# Deutsch Macht — دوره آلمانی میشل توماس 🇩🇪🇮🇷

اپلیکیشن اندروید آموزش زبان آلمانی بر اساس جزوه فارسی دوره میشل توماس (۱۰ درس، ۱۱۱۴ واژه و جمله).

## امکانات
- 📚 ۱۰ درس کامل با ترجمه فارسی (RTL)
- 🔊 تلفظ آلمانی با TTS سیستم
- ✅ علامت‌گذاری واژه‌های یادگرفته‌شده + نمایش پیشرفت
- 📝 آزمون چهارگزینه‌ای (دوسویه: آلمانی↔فارسی) با ثبت بهترین نمره
- 🔍 جستجو در همه درس‌ها (فارسی و آلمانی)
- 🌙 پشتیبانی از حالت تیره

## بیلد
نیازمند JDK 17 و Android SDK (API 34):

```bash
./gradlew assembleRelease
```

خروجی: `app/build/outputs/apk/release/app-release-unsigned.apk`

بیلد خودکار با GitHub Actions روی هر push به `main` انجام می‌شود و APK به‌صورت Artifact آپلود می‌شود.

## داده
`app/src/main/assets/lessons.json` — استخراج‌شده از PDF جزوه با اسکریپت `parse_pdf.py`.
